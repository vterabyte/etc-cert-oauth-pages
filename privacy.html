プライバシーポリシー

「ETC利用証明書 Drive保管」(以下「本アプリ」)は、V Limousine の業務のために運用している社内向けツールです。 本アプリが Google アカウントのデータをどのように扱うかを以下に定めます。

1. 取得する情報

本アプリは Google OAuth を通じて、利用者自身の Google ドライブへのアクセス権(https://www.googleapis.com/auth/drive)の許可を求めます。 アクセスするのは、利用者が指定した保管用フォルダ配下のファイル(ETC 利用証明書 PDF、台帳 CSV、カードマスタ CSV)に限ります。

2. 利用目的

  • ETC利用照会サービスから発行した利用証明書 PDF を、指定フォルダへ保存すること
  • 保存済みの走行を記録した台帳ファイルを読み書きし、重複発行を防ぐこと

上記以外の目的で Google ドライブのデータを読み取り、保存、転送することはありません。

3. 第三者への提供

Google ドライブから取得した情報を第三者に提供、販売、共有することはありません。 Google API から取得した情報の利用は、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に従います。

4. データの保管と保護

OAuth の認証トークンは、本アプリを実行するための暗号化された設定領域(GitHub Actions の Secrets)にのみ保管し、公開リポジトリやログには記録しません。 証明書 PDF と台帳は利用者自身の Google ドライブ内に保存され、本アプリの運営者が別途保持することはありません。

5. アクセス権の取り消し

利用者は Google アカウントの「サードパーティ製のアプリとサービス」からいつでも本アプリのアクセス権を取り消せます。

6. 改定

本ポリシーを変更する場合は、このページで公開します。
